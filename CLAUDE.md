# Claude Code Instructions

Use `AGENTS.md` as the primary AI operating guide for this repository.

Before performing any work:

1. Read `AGENTS.md`.
2. Read `PROJECT_CONTEXT.md`.
3. Read `docs/project/SOURCE_OF_TRUTH.md`.
4. Read `ai/rules/NON_NEGOTIABLES.md`.
5. Follow the required reading order defined in `AGENTS.md`.
6. Identify the source-of-truth documents relevant to the task.
7. Do not create or modify code until the project constraints are understood.

Do not introduce new:

- Product claims
- Clinical claims
- Features
- Integrations
- Regulatory statements
- Brand directions
- Architectural patterns

unless they are supported by approved repository documentation.

When a material decision is not documented, record it in:

`docs/project/OPEN_QUESTIONS.md`

Do not invent an answer or treat temporary chat context as an approved project decision.
