# ODRISC Website

The official website repository for ODRISC, a maternal and fetal intelligence platform supporting longitudinal clinical understanding, earlier recognition, better monitoring, and improved maternal and fetal outcomes.

## Current Project Stage

Documentation and AI knowledge-base foundation.

Application development has not yet started.

## Repository Structure

- `PROJECT_CONTEXT.md` — Canonical project context
- `AGENTS.md` — Instructions for AI agents
- `docs/` — Product, design, content, SEO, and engineering documentation
- `ai/` — AI rules, workflows, personas, and decision records
- `reference/` — Source material and design references
- `assets/` — Working visual assets
- `src/` — Application source code, to be created during development
- `public/` — Production static assets

## Required Reading

Every contributor should begin with:

1. `AGENTS.md`
2. `PROJECT_CONTEXT.md`
3. `docs/project/SOURCE_OF_TRUTH.md`
4. `ai/rules/NON_NEGOTIABLES.md`

## Development Status

The Next.js application should not be initialized until the foundational project documentation has been approved.

## Product Principle

The repository documentation is the durable project memory. Important decisions must be documented rather than left only in chat histories or temporary prompts.
