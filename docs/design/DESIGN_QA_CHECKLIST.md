# ODRISC Design QA Checklist

## Item

- Page ID or component:
- Audience:
- Market:
- Language:
- Reviewer:
- Review date:

## Tokens

- [ ] Approved colors are used
- [ ] No undocumented spacing values appear
- [ ] Approved radii and borders are used
- [ ] Shadows follow the elevation system
- [ ] Typography follows the approved scale

## Layout

- [ ] Correct container width is used
- [ ] Correct grid is used
- [ ] Mobile layout is complete
- [ ] Tablet layout is complete
- [ ] Large-screen layout does not stretch excessively
- [ ] Long content is supported

## Components

- [ ] Existing components are reused
- [ ] All required states are designed
- [ ] Loading, empty, success, and error states are present
- [ ] Product Status is displayed correctly
- [ ] Clinical and semantic colors are not confused

## Accessibility

- [ ] Contrast passes
- [ ] Focus is visible
- [ ] Keyboard order is logical
- [ ] Interactive targets meet 44px minimum
- [ ] Meaning does not depend on color
- [ ] Reduced motion is supported
- [ ] Charts and diagrams have alternatives
- [ ] Text scales without loss of content

## Audience

- [ ] Patient density is appropriate
- [ ] Provider density is appropriate
- [ ] The experience remains recognizably ODRISC
- [ ] Audience switching is visible where required

## Localization

- [ ] Long translations fit
- [ ] Arabic typography is supported
- [ ] RTL layout is reviewed
- [ ] Directional icons behave correctly
- [ ] Numbers, dates, currencies, and units are readable

## Result

- [ ] Approved
- [ ] Approved with revisions
- [ ] Requires accessibility revision
- [ ] Requires RTL revision
- [ ] Requires Product Status revision
- [ ] Rejected
