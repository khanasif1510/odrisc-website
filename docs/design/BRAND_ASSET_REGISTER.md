# ODRISC Brand Asset Register

## Purpose

This document records all approved, draft, placeholder, deprecated, and retired ODRISC brand assets.

No asset should be treated as approved solely because it appears in a presentation, mockup, repository folder, or generated design.

## Asset Status

| Status      | Meaning                                              |
| ----------- | ---------------------------------------------------- |
| Placeholder | Temporary asset used only for layout or concept work |
| Concept     | Candidate asset under review                         |
| Draft       | Asset selected for refinement but not approved       |
| Approved    | Authorized for defined public use                    |
| Restricted  | Approved for limited or internal use                 |
| Deprecated  | Should no longer be used in new work                 |
| Retired     | Removed from active use                              |
