# ODRISC Brand Review Checklist

## Project Information

- Asset or page:
- Page ID:
- Audience:
- Market:
- Language:
- Reviewer:
- Review date:

## Strategy

- [ ] ODRISC product identity is correct
- [ ] Audience is clear
- [ ] Website Story is preserved
- [ ] Product Status is accurate
- [ ] Brand purpose is supported

## Voice

- [ ] Tone matches the audience
- [ ] Language is clear
- [ ] Claims are proportionate
- [ ] Clinical boundaries are visible
- [ ] Prohibited language is absent
- [ ] Terminology follows the Glossary

## Visual

- [ ] White remains the dominant background
- [ ] `#4d4d4d` is used appropriately for text
- [ ] Gradient use is restrained
- [ ] Negative space supports comprehension
- [ ] Visual hierarchy is clear
- [ ] Generic AI imagery is absent
- [ ] Patient stereotypes are absent
- [ ] Concept assets are labeled

## Accessibility

- [ ] Text contrast is sufficient
- [ ] Meaning does not depend on color
- [ ] Motion can be reduced
- [ ] Images and diagrams have alternatives
- [ ] Typography remains readable
- [ ] Mobile reading order is logical
- [ ] Arabic and RTL needs are considered

## Trust

- [ ] Product maturity is transparent
- [ ] Validation claims are precise
- [ ] Team and partnership claims are verified
- [ ] Market availability is accurate
- [ ] Security and privacy claims are confirmed

## Result

- [ ] Approved
- [ ] Approved with revisions
- [ ] Rejected
- [ ] Requires clinical review
- [ ] Requires legal or privacy review
- [ ] Requires accessibility review
