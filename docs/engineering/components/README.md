# ODRISC Component Specifications

Individual component specifications are stored in this directory.

File naming:

`<Component-ID>-<component-name>.md`

Examples:

- `CMP-NAV-005-audience-switcher.md`
- `CMP-FRM-007-provider-demo-request-form.md`
- `CMP-TRS-001-product-status-badge.md`
- `CMP-FTR-207-provider-workflow.md`

Use:

`docs/design/COMPONENT_SPEC_TEMPLATE.md`

A specification is required before implementation for navigation, forms, consent, charts, Product Status, major motion, and clinically material feature components.
