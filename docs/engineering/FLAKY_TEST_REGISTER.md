# ODRISC Public Website Flaky Test Register

## Register

| Flaky ID | Test ID | First observed | Failure pattern | Product or test issue | Owner | Risk | Temporary action | Target resolution | Status |
| -------- | ------- | -------------- | --------------- | --------------------- | ----- | ---- | ---------------- | ----------------- | ------ |

## Rules

- A passing retry is recorded as flaky.
- P0 tests may not be quarantined.
- Security, privacy, accessibility, and clinical-safety tests may not be hidden.
- Non-P0 quarantine requires QA-owner and CTO approval.
- Each entry must have a target resolution date.
