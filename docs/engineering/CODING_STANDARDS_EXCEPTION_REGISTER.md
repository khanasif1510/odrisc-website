# ODRISC Coding Standards Exception Register

## Purpose

This register records approved, temporary exceptions to the public-website
Coding Standards.

## Rules

- Every exception must have an owner.
- Every exception must have a defined scope.
- Every exception must include mitigation.
- Temporary exceptions must have a review or expiry date.
- Security, privacy, clinical-safety, and accessibility issues cannot be accepted
  as indefinite exceptions.
